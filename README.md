# مسار الصيانة | Masar Field Maintenance

تطبيق ويب عصري متكامل (RTL) لإدارة الصيانة الميدانية وتتبع الفنيين والمواقع والأوقات لحظياً، مدعوم بـ **GSAP** و**CSS Animations** وتصميم متجاوب بالكامل للموبايل والكمبيوتر مع الوضع الليلي.

## المميزات الرئيسية
- **صفحة المدير (Manager Dashboard):** لوحة تحكم عصرية لإدارة البلاغات، تعيين الصيانات وتحديد اللوكيشن والأوقات، متابعة مؤشرات الأداء، خريطة GPS تفاعلية للمواقع والفنيين، وقائمة "محتاج متابعة" مع SLA.
- **صفحة الفني / الموظف (Technician Portal):** عرض مهام اليوم وأوقات الوردية وتفاصيل الموقع والاتجاهات عبر Google Maps وقائمة فحص الصيانة وتقرير الحل.
- **بار التتبع المتحرك المتقدم (GSAP + CSS Animations):** يتتبع رحلة الفني عبر 6 مراحل من استلام البلاغ وحتى الوصول للمركز وحل المشكلة مع عداد إنجاز ومسافة متحرك ومسار SVG وميزة المحاكاة التلقائية واحتفالية الإنجاز.
- **دعم كامل للموبايل والوضع الليلي.**

## التشغيل المحلي
```bash
npm install
npm run dev
```

## البناء للإنتاج
```bash

npm start
```
